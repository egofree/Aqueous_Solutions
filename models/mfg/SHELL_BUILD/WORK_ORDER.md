Authority: AQS-DUTY-072 (X-MFG lane). LIVE unit - shell-building booth.

1. Fabricate the booth frame with back-wall cladding; set on anchors.
2. Set the 40 L slurry tank with the rainfall stucco station and reclaim pan.
3. Erect the manipulator mast over the dip deck; prove the 6-position cycle.
4. Fit the N1 pattern chute, the N3/N4 silica inlets, the N2 green-shell out, N5 drain and N6 vent.
5. Test: slurry viscosity hold, then a trial shell on a wax pattern.
6. Inspect against models/mfg/SHELL_BUILD/export/shell_build.step; record dimensions on the traveller.
