# Work order MFG_SHOP

Plan AQS-PLAN-006 (section 2 work order; section 5 acceptance A-core + A-MACH + A-SC). Route class F-MACH (the `shop` class sits in the F-MACH row of plan section 4). Graph Rev AD. Status M3. Study. Not a PE stamp.
Authority: `docs-authority/duties/MFG_SHOP.md`, `docs-authority/nozzles/MFG_SHOP.csv`, AQS-STD-001 (shop rule), AQS-MFG-010 (Table 2.1 tool roster, rev C metering split), AQS-EQP-MFG-001 (massing roster pointer), AQS-MOD-002 (frame standard), `flow_graph/plant_flow_graph.json` node MFG_SHOP (continuous note).

## Per-unit items

W1 Source. `mfg_shop.py` (CadQuery) reads `params.json` only and rebuilds every solid. The W2 fields of `params.json` are tracker-generated; the `envelope`, `design` and `layout` blocks are builder-owned and pass through tracker regeneration.
W2 Envelope. The node carries `size_mm` 1000 × 600 × 800 (the M0 study registry box). The build fills it: measured 1000.0 × 600.0 × 800.0 mm from the export STL — the four-post hold-down/guard frame pins the box so the X-PAR-04 envelope registry reads the build.
W3 Internals. The node carries `internals: none`, so the tracker records no internal solid. The machine is drawn as the unit per the node continuous note's authority (AQS-MFG-010 rev C, Table 2.1): since the rev C metering split the unit covers the six shop machine tools only — CNC vertical mill (7.5 kW), engine lathe (5.5 kW), band saw (1.5 kW), rotary-screw air compressor (4.0 kW), TIG/MIG welder (6.0 kW), bench grinder/drill-press/hand-tool set (2.0 kW) — connected 26.5 kW, one 8 h shift, average 2.55 kW (61.2 kWh/d). Stations are purchased-class machine envelopes per plan rule 6: envelope and interface, named with the nameplate from the tool row, no invented internals. The four metal-forming tools (melt, atomiser, mill, drawer) are metered at their own units and are not part of this fitout; the AQS-EQP-MFG-001 polymer-line massing tags (shredder, wash/dry, extrusion, injection, sheetpress) are area equipment, not graph units. Shop-air DN15 header with four drop legs on the compressor service.
W4 Nozzles. All 33 rows of the issued schedule `docs-authority/nozzles/MFG_SHOP.csv` are drawn at tag, face, height and bore as atmospheric open-bore tube stubs flush at the envelope faces: the stock rows on −Y at z 160 include the DN25 metals/Si and glass/ceramic stock rows and the 19 solids rows (goods, scrap returns, plated sheet, stock issues — non-piped transfers drawn DN15, bore not calculated, plan W4); N5-N8 and N16/N33 on +Y at z 600 with N7 goods-in-service the DN50 row; N9 drain flush at the envelope bottom (50 datum); N10 vent flush at the envelope top (800 datum is the box top). Duty section 4: DN15, no flange class, atmospheric tube or hose; no flange is drawn because no process pressure is stated (W4 110 % rule); the schedule rating column (Class 150) is carried verbatim as text. Nozzle elevations are schedule placeholders (unit tasks 02/06 — hold, W12).
W5 Fasteners. `fasteners.csv`: 8 M12 wedge anchors (plinth to slab, 2 per frame post line) and 12 M10 machine hold-down bolts (2 per station), counts from the model. 8.8 on carbon steel per the grade rule; lengths and patterns are study values, confirmed at fabrication.
W6 Materials. Duty section 3: 316L where the stream is wet — dry shop machines, so CA 0 mm shop practice applies and the 316L row is carried for the connection stubs and the shop-air header. Bench, deck, frame and plinth carbon steel A500 (AQS-MOD-002 dry service).
W7 Pressure. Atmospheric shop; the duty section 6 relief case is pending (unit task 07) and no set point is claimed. Duty section 5: level and temperature where the node is a liquid holdup — no liquid holdup on this node; no trip is specified.
W8 Exports. `export/mfg_shop.step` (assembly, 34 solids); `export/mfg_shop.stl` closed and manifold; `cad/stl/MFG_SHOP.stl` replaced from the in-envelope build solid (ASCII, metres, X-PAR-04 registry). Bounding box 1000.0 × 600.0 × 800.0 mm against the node envelope: filled exactly.
W9 BOM. `bom.csv`, generated from the model: quantity, material, mass, make-or-buy, basis. Make rows carry the AQS-BOM-SC-001 flag (A-SC): bench deck/plinth, hold-down/guard frame, shop-air header, nozzle set. Buy rows (purchased per plan rule 6, nameplates from AQS-MFG-010 Table 2.1): the six machine stations (CNC mill 7.5 kW, lathe 5.5 kW, band saw 1.5 kW, air compressor 4.0 kW, welder 6.0 kW, bench set 2.0 kW; station masses are study envelopes at carbon-steel density apportioned by envelope volume — maker prints govern at order).
W10 Fabrication route. F-MACH (plan section 4: frame weldment, guards, purchased drive or electrical by rating, anchors): plate cut and weld (bench, frame), machine bay preparation (levelled pads, hold-downs), machine set and anchor, utility hookups (shop-air header, drop legs), guards, then machine alignment checks and a first-article part per machine class. On-site tool: the shop installs its own machines; the machines are maker items.
W11 Self-copy relevance. This is the shop that makes the plant's shop-made parts: the AQS-BOM-SC-001 make rows flagged across the accepted units land here. The fitout's own make rows (bench, frame, header, connections) are flagged with the same cross-reference (tier-7 A-SC set). The machine stations themselves are buy rows — their make/buy split for plant parts is the AQS-BOM-SC-001 register's scope.
W12 Holds, named. (1) Machine envelope footprints are study values; the maker prints govern at order. (2) The 19 solids rows are drawn DN15, bore not calculated (W4 rule). (3) Nozzle elevations are schedule placeholders (unit tasks 02/06). (4) Station masses are table-density placeholders until the maker prints quote. (5) The relief case is pending (unit task 07). (6) Fastener lengths and anchor embedment are study values, confirmed at fabrication. (7) The duty section 8 open item stands: no holdup basis for this class — none claimed; and the S08/S16 provenance notes are balance-lane items, not machine facts. (8) The hall programme and bin-hour loads (duty section 2 of EXT_HALL) are hall-lane items; the shop fitout carries the AQS-MFG-010 machine roster only.
