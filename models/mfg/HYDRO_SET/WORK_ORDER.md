## Per-unit items

W1 Source. `hydro_set.py` (CadQuery) reads `params.json` only and rebuilds every solid. The W2 fields of `params.json` are tracker-generated; the `envelope`, `design` and `layout` blocks are builder-owned and pass through tracker regeneration.
W2 Envelope. The node carries `size_mm` 1000 × 600 × 800 (the M0 study registry box). The build fills it: measured 1000.0 × 600.0 × 800.0 mm from the export STL — the four-post hold-down/guard frame and the vent riser pin the box so the X-PAR-04 envelope registry reads the build.
W3 Internals. The node carries `internals: none`, so the tracker records no internal solid. The machine is drawn as the unit per the node backup_basis (A-M-145 lane; Q-006/Q-009 closed): the pumped-hydro N+1 backup of ZNBR2 (third source FUEL_CELL) to NFPA 111 Level 1, Class X — 14 h at the 14.46 kW critical load = 202.4 kWh at the bus. The set is drawn as purchased-class machine envelopes per plan rule 6 with the node ratings: turbine envelope (rated_kW_discharge 14.46 at head_m 36.21, eta_turbine_generator 0.8), generator envelope, pump-motor envelope (recharge 49.6 kW over the PV window, eta_pump_motor 0.85; round_trip 0.68), electrical cabinet envelope, and a buffer manifold vessel (OD 160 × 300, study — W12). No machine type is invented: the envelopes are the model; the maker prints govern.
W4 Nozzles. All 3 rows of the issued schedule `docs-authority/nozzles/HYDRO_SET.csv` are drawn at tag, face, height and bore as atmospheric open-bore tube stubs flush at the envelope faces: N1 hydro turbine-pump electrical out on +Y at z 600 (schedule service text verbatim, including the "MISSING on SLD" note — the one-line update is an electrical-lane item); N2 drain flush at the envelope bottom (50 datum); N3 vent flush at the envelope top (800 datum is the box top). Duty section 4: DN15, no flange class, atmospheric tube or hose; no flange is drawn because no process pressure is stated (W4 110 % rule); the schedule rating column (Class 150) is carried verbatim as text.
W5 Fasteners. `fasteners.csv`: 8 M12 wedge anchors (plinth to slab, 2 per frame post line) and 8 M16 set-base bolts (2 per machine bay), counts from the model. 8.8 on carbon steel per the grade rule; lengths and patterns are study values, confirmed at fabrication.
W6 Materials. Duty section 3: 316L where the stream is wet — CA 0 mm shop practice; the water sides (reservoirs, penstock, tailrace) are building scope, so the 316L row is carried for the buffer vessel and connection stubs. Frame and plinth carbon steel A500 (AQS-MOD-002 dry service).
W7 Pressure. The reservoir head (36.21 m) acts on the penstock, which is building scope (AQS-BLD-014, A-M-187); no design_kPa is stated on this node and the duty section 6 relief statement says the stored head-plus-10 figure "is not a set point" — nothing is claimed here. Duty section 5: level and temperature where the node is a liquid holdup; high level trips the inlet — the trip circuit is control hardware (W12).
W8 Exports. `export/hydro_set.step` (assembly, 3 solids); `export/hydro_set.stl` closed and manifold; `cad/stl/HYDRO_SET.stl` replaced from the in-envelope build solid (ASCII, metres, X-PAR-04 registry). Bounding box 1000.0 × 600.0 × 800.0 mm against the node envelope: filled exactly.
W9 BOM. `bom.csv`, generated from the model: quantity, material, mass, make-or-buy, basis. Make rows carry the AQS-BOM-SC-001 flag (A-SC): plinth, hold-down frame, buffer vessel, interface pads, nozzle set. Buy rows (purchased per plan rule 6, ratings from the node): turbine envelope (14.46 kW discharge class), generator envelope, pump-motor envelope (49.6 kW recharge class), electrical cabinet.
W10 Fabrication route. F-MACH (plan section 4: frame weldment, guards, purchased drive or electrical by rating, anchors): skid and frame weldment, buffer vessel shell (F-VES practice: plate cut, roll, weld, nozzle set-in, leak test), machine set mounting and alignment, anchor, then a wet spin test at the tailrace class with the reservoir isolation proven. On-site tool: the metal shop welding bay; the machine sets are maker items.
W11 Self-copy relevance. The set makes bus energy, not plant parts; A-SC applies to the shop-made hardware flagged in the BOM with the AQS-BOM-SC-001 cross-reference.
W12 Holds, named. (1) No machine type is named on the node (impulse/reaction class, specific speed) — the envelopes are the model and the maker prints govern. (2) The penstock and tailrace bores are not calculated (W4) — the reservoir structures and penstock routing are building scope (AQS-BLD-014, A-M-187, Q-009). (3) The buffer vessel size is a study value. (4) The N1 SLD MISSING note stands (electrical-lane one-line update). (5) The envelope masses are table-density placeholders until the maker prints quote. (6) The high-level trip circuit is control hardware, not modeled. (7) The continuous kW model is honest-incomplete on the node (WP-A4) — nothing claimed here; the standby state reads the S43/S44 class loop at 0 kW idle. (8) Fastener lengths and anchor embedment are study values, confirmed at fabrication.
