# Work order FILM_CAST

Authority: AQS-DUTY-072 (X-MFG lane). LIVE unit - PVDF cast film line.

1. Fabricate the line frame with the bed; set on anchors.
2. Fit the extruder (316L barrel), hopper and drive; fit the Hastelloy die.
3. Set the chill roll, pressure roll, draw rolls and winder; align the web path.
4. Fit the N2 resin inlet, N1 film stop, N3 drain and N4 vent.
5. Test: extruder dry heat at 220 C, then a trial web from POLY_F N5 resin.
6. Inspect against models/mfg/FILM_CAST/export/film_cast.step; record dimensions on the traveller.
