# Work order CA_POT

Authority: AQS-DUTY-072 (X-MFG lane). LIVE unit - D-DOCK feedstock program (A-M-284).

1. Fabricate the 800 x 800 x 1600 mm shell; line 70 mm (casing + ceramic fibre + ram) for 700 C service.
2. Set the 2 cathode plates on the pocket wall; hang the 3 x D50 mm anodes at 250 mm immersion.
3. Fit the busbar ladder (25 mm2 Cu class for 3.61 A) and the DC drops; torque and megger-check.
4. Mount the hood, DN50 offtake with return dip leg, N3 Cl2 stub, and the N2 brine chute with lance.
5. Wire the 1.0 kW rectifier; interlock hood draft, bath temperature and cover position.
6. Test: dry-out and melt-up curve, then trial electrolysis; tap the Ca metal at N1, route the Cl2 export (water-treatment class).
7. Inspect against models/mfg/CA_POT/export/ca_pot.step; record dimensions on the traveller.
