# External open-source dependencies

This publish tree links to the projects below; it does not redistribute their
files. Each entry is attribution for the external design reference used by
Aqueous, not a claim that the upstream project endorses Aqueous.

## Precious Plastic

- **Project:** Precious Plastic / `precious-plastic-kit` (V4.1 archive context)
- **Role in Aqueous:** Open-source plastic-recycling machine and workspace
  reference used in the MFG section.
- **Public URLs:**
  - [Precious Plastic](https://preciousplastic.com/)
  - [ONEARMY/precious-plastic-kit](https://github.com/ONEARMY/precious-plastic-kit)
  - [Precious Plastic download kit](https://community.preciousplastic.com/library/download-kit)
- **License:** Creative Commons Attribution (the official project describes
  its content as CC Attribution; check the terms for any particular asset).
- **Distribution:** **Not bundled — link only.** The local 2.1G archive copy is
  not copied into `share/aqueous-solutions/`.

## SEM-Tech / open-sourced off-the-shelf ion-exchange membrane

- **Project:** Open-sourced-off-the-shelf-ion-exchange-membrane
- **Role in Aqueous:** Open membrane design and fabrication reference for the
  wet line and BMED membrane work, and preferred **IEM** for the MeOH train
  (AQS-MeOH-001 MEOH_IEM_CELL / MEOH_FC).
- **Fork used for attribution:**
  [egofree/Open-sourced-off-the-shelf-ion-exchange-membrane](https://github.com/egofree/Open-sourced-off-the-shelf-ion-exchange-membrane)
- **License:** CC0 1.0 Universal (the egofree fork).
- **Upstream / fork parent:**
  [Rowow-LLC/Open-sourced-off-the-shelf-ion-exchange-membrane](https://github.com/Rowow-LLC/Open-sourced-off-the-shelf-ion-exchange-membrane)
  — CERN Open Hardware Licence Version 2, Strongly Reciprocal
  (CERN-OHL-S-2.0).
- **Distribution:** **Not bundled — link only.** No membrane repository files
  are copied into this publish tree.
