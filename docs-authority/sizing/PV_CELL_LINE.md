## 1. Purpose and scope

This page sizes the tools of the photovoltaic (PV) cell line `SOLAR_PV_CELL` in the FAB sector, which turns wafers into solar cells. It gives the design, the peak power and the daily energy of each tool.

## 2. Method

The line makes 3 cells a day in one batch. The tools run one after another, so the peak power of the line is that of the largest tool.

Table 2.1 gives the tools.

The peak power of the line is 3.79 kW. The line uses 9.40 kWh/d, an average of 0.392 kW, or 3.13 kWh per cell. Tool PV-EMIT-01 uses the most energy; running a second batch in the same heat would spread its heat-up over twice as many cells.
The heat-up masses, the RF power density, the lamp power and the run times are assumptions until the first article of each tool has been run (A-M-178).
