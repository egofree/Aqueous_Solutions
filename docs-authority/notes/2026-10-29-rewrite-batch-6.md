# Rewrite batch 6: instrument index, inspection and test plan, load list, internals and unit materials

Date: 2026-10-29

Five generated pages were rewritten through their generators: the instrument index (`_instr_index.py`), the inspection and test plan (`_itp.py`), the load list (`_load_list.py`), the internals register (`_internals.py`) and the per-unit material selections (`_unit_materials.py`). Each page now has a record of revisions, a purpose and scope section, its summary written as sentences and numbered tables.

The counts in the summaries are computed by the generators. The first revisions of the internals register and the material selections gave fixed counts of units and wetted rows; the line list now has more wetted stream ends than the fixed count stated, so those counts were removed from the text.

No values changed. The material selections page no longer prints an empty table when no unit is open.
