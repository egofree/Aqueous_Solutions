# Nutrient gaps

Document number: AQS-DUTY-048
Revision: A
Date: 2026-10-09
Authority: farm model a532d2e. Four people. Study. Not a PE stamp.

| Nutrient | Farm supply | Missing | Close |
|---|---|---|---|
| Calories | Potato covers the staple share | Oil crops not on the yield sheet | Peanut and sunflower yields |
| Nitrogen | Fish, urine, clover, azolla | About 17 g/d against gross uptake | Residue return, then azolla area |
| Phosphorus | Fish 1.4 g/d, urine 0.8 g/d | 5.8 g/d before recycle | Struvite, bone, manure |
| Potassium | Fish 2.2 g/d, urine 2.5 g/d | 39 g/d against uptake | Ash and stalks, then leach potassium |
| Calcium | Urine, compost | Not closed | Hydroxide cake if it drifts |
| Magnesium | Feed and compost | None at this duty | Hydroxide cake if it drifts |
| Sulfur | Feed | None at this duty | None |
| Iron | Present, not soluble | Soluble iron | Ferric citrate from electrowon iron |
| Manganese, zinc, copper | Feed | None at this duty | Electrowon metal if it drifts |
| Boron | Feed | None at this duty | Brine borate if it drifts |
| Molybdenum | Feed, needed by nitrogenase | Thin | Polish cake if it drifts |
| Iodine | None | All of it | Iodide from the leach |
| Vitamin B12 | Eggs, milk, fish | None if those are eaten | Keep the animals |
| Vitamin D | Lighting | None if the spectrum is right | Lighting duty |

Phosphorus and iodine are not made by the farm. Potassium is the largest mass hole. Nitrogen is closable without the Haber store.
