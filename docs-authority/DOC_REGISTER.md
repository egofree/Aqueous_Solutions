## 1. Purpose and scope

Every controlled page in this repository carries a document number, such as AQS-SEC-001, so that other pages, drawings and tests can cite it without depending on its file name. This register lists every number in use, the page that holds it, the revision and date that page states, and whether a later page has superseded it. It also lists the numbers that pages held before they were renumbered, so that a reader can resolve a citation found in an older document.

The register covers every tracked Markdown page that states a document number in its first lines. It does not judge whether a page is complete or correct; the task plan (AQS-PLAN-007) tracks that.

## 2. Numbering rules

- Each number belongs to one page. The page states it in its first lines as `Document number: AQS-XXX-NNN`, where `XXX` is the series and `NNN` is the sequence number within the series.
- Every page directly under `docs-authority/` has a number. Folder indexes (`README.md`) do not.
- A new page takes the next free number in its series. Run `python3 docs-authority/_doc_register.py --next AQS-XXX` to find it.
- A page that is renumbered keeps its old number on a `Former number:` line, so that older citations can still be resolved (section 4). A former number is never issued again. Where two pages once shared a number, a citation of that number dated before 2026-10-24 may refer to either page; section 4 names both.
- When a page is deleted, its number is withdrawn and listed in section 6. A withdrawn number is never issued again.
- A number followed by a qualifier, for example `AQS-INV-005 sheet MF-01`, names a part of that document and is listed in section 5.
- The test `flow_graph/test_doc_numbers.py` fails if a number is claimed twice or if a page that needs a number has none.
