# EVAP_BASE fabrication

Envelope 1250 x 800 x 3100 mm.
Design pressure 100.0 kPa gauge body (full vacuum), 350.0 kPa gauge steam shell.
Internals: 20 falling-film tubes, distributor, mesh pad.

Production route (MFG/FAB, in-house, X-MFG-30):
1. Tubes and tubesheets: nickel 200 (tube, sheet). Nickel: roll and seam-weld strip to tube (GTAW), expand into drilled tubesheets and seal-weld.
2. Shell and separator: roll and weld plate; nickel 200 plate, GTAW; flanges ISO 7005-1 PN10.
3. Blower: cast and machine impeller and volute on the MFG line; dynamic balance ISO 21940-11 grade G2.5; motor IEC 60034 frame (X-MFG-32).
4. Interchanger: nickel plate pack, brazed or gasketed, 0.146 m2.
5. Assembly, hydrotest 1.43 x design, relief valves set and sealed, insulation.

Nozzles per the line list. Shop weld. Not stamped.
