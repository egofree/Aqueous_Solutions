# POLY_COND fabrication

Envelope 600 x 600 x 1200 mm shell over the 200 x 300 mm kettle (real kettle geometry issued at
the design case, A-M-283; installed standby). Atmospheric (kettle at the vent datum; jacket 160 C
design temperature).

Production route (MFG/FAB, in-house, X-MFG-31):
1. Kettle: 316L welded vessel, 200 mm ID x 300 mm straight side, dished heads, 160 C jacket,
   DN25 jacket stubs (graph design; Hastelloy C option stays the alternate for the assayed recipe,
   AQS-DES-POLY).
2. Agitator: 0.18 kW direct drive per the graph design row; anchor-to-drive guard on the shop
   standard.
3. Condensate route: vapour line stubs per nozzles/POLY_COND.csv; chem feed port for the assayed
   recipe charge when AQS-DES-POLY issues.
4. Test: water fill and jacket circulation hold at 160 C on the Q3 spare leg; inert pressure hold
   per AQS-STD-001 sec. 4.

Inspect against models/mfg/POLY_COND/export/poly_cond.step. Not stamped. Installed standby: the
production rate stays 0.0 until the digester organic assay issues (AQS-DES-POLY, A-M-267); the
design case 0.5 kg/d is booked with the per-kg tables in AQS-DUTY-073.
