# EVAP_ACID fabrication

Envelope 1650 x 1300 x 3800 mm.
Design pressure 100.0 kPa gauge body (full vacuum), 350.0 kPa gauge steam shell.
Internals: 22 falling-film tubes, distributor, mesh pad.

Production route (MFG/FAB, in-house, X-MFG-30):
1. Tubes and tubesheets: impregnated graphite (block, tube, tubesheet). Graphite: extrude or machine from block, vacuum-impregnate with phenolic or furan resin, cure; bond tubes into tubesheets with the same resin cement.
2. Shell and separator: roll and weld plate; PTFE sheet lining, thermoformed and welded; flanges ISO 7005-1 PN10.
3. Blower: cast and machine impeller and volute on the MFG line; dynamic balance ISO 21940-11 grade G2.5; motor IEC 60034 frame (X-MFG-32).
4. Interchanger: graphite block, cross-drilled, 0.15 m2.
5. HCl column and vent scrubber: glass column sections per AQS-DUTY-060 section 7; EVAP_ACID_VS PVC-U scrubber per docs-authority/fab/EVAP_ACID_VS.md, clamped to the frame.
6. Assembly, hydrotest 1.43 x design, relief valves set and sealed, insulation.

Nozzles per the line list. Shop weld. Not stamped.
