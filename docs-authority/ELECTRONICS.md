# Electronics bay

Document number: AQS-ELEC-001
Revision: B
Date: 2026-10-10

1. Basis. Large-geometry device. Minimum line 100 µm.

2. Size. Six stations: coat, align, develop, etch, strip, probe. Each is one module frame. Bay is 6 × 1.2 = 7.2 m. Etch is the wet bench. Probe has two manipulators, 10 µm, shop-built.

3. Material. Frames A500. Benches PP.

4. Nozzles. Each station has the module power connector. Wet stations have a DN15 drain to the leach.

5. Instruments. Per station, as the aligner and the wet bench.

6. Relief. Wet stations vent to the scrubber.

7. Code. Shop.

8. Open items. No device layout is drawn. The line width and the bay are.
