# Module standard

Document number: AQS-MOD-001
Revision: A
Date: 2026-10-10
Authority: critical path item 1. Not a PE stamp.

A module is a frame, a power connection, and a fluid connection. The process sits inside. Any module bolts to any bay.

Frame. 4x4x1/4 inch steel tube, 1200 x 600 x 800 mm outside. Four feet. Lift points at the top corners. This is the OSE tube size.

Power. One connector, 48 V DC, 100 A, Anderson SB350. A module that needs more current takes a second connector. The electrowinning rack does.

Fluid. Two quick couplers, 12 GPM, pressure and return. A third coupler, 28 GPM, is optional. This is the OSE power-cube pair.

Parametric. Envelope, current, and coupler count are the three parameters. A script changes them. The frame pitch does not change.

First three modules on this frame: the lathe, the electrowinning cell, the induction furnace.
