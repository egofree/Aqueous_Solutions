# DUAL_ROOT

Standard: AQS-STD-001 Rev A. Graph Rev BG. Study. Not a PE stamp.

1. Basis. Mass in 20.00 kg/d. Mass out 20.00 kg/d. Electrical duty 0.3000 kW. In: IA-DR-IN 20.00 kg/d (correction supply). Out: IA-DR-OUT 20.00 kg/d (correction return, not to the tank).

2. Size.
- Envelope 6000×2000×600 mm, 7.20 m³. That box over this flow would be 8640.0 h if it were full. It is not a residence time.
- Seven-day charge V = (20.00/1000)×(168/24) = 0.1400 m³.

3. Material. HDPE or PVC for the water. The frame is not the wetted part. Corrosion allowance does not apply to the polymer.

4. Nozzles. At 1.5 m/s and 1000 kg/m³ the bore is 0.44 mm. That is not a specification. Nozzle is DN15. No flange class. Atmospheric tube or hose. Not to the room.

5. Instruments. No trip is specified.

6. Relief. Not a pressure vessel. A vent, if the shell is closed, returns to the process. Not to the room. Stored design_kPa is the old head-plus-10 figure. It is not a set point.

7. Code. Shop. Not stamped.

8. Open items. Envelope volume over flow is not a residence time.
