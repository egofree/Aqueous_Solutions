# H2_DRYER

Standard: AQS-STD-001 Rev A. Graph Rev BF. Study. Not a PE stamp.

1. Basis. Mass in 6.64 kg/d. Mass out 6.64 kg/d. Electrical duty 0.3000 kW. In: IA-HDR-H2-02 6.64 kg/d (process H2). Out: S05 6.64 kg/d (process H2).

2. Size.
- The largest edge is gas. This class is not a scrubber. No tower diameter is calculated from 1.5 m/s.

3. Material. 316L where the stream is wet. Corrosion allowance is not set.

4. Nozzles. No duct bore. Density is not on the edge, and 1.2 kg/m³ is not used. Rating is not set. The vent stays on the gas edge, not the room.

5. Instruments. Level and temperature where the node is a liquid holdup. High level trips the inlet.

6. Relief. The set point is not assigned. DN15 back to the suction of this loop. Not to the room and not to a stack. Stored design_kPa is the old head-plus-10 figure. It is not a set point.

7. Code. Shop. Not stamped.

8. Open items. No vessel diameter. Duct bore is not calculated.
