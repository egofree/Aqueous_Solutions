# STRUVITE

Standard: AQS-STD-001 Rev A. Graph Rev BG. Study. Not a PE stamp.

1. Basis. Mass in 0.2000 kg/d. Mass out 0.2000 kg/d. Electrical duty 0.2000 kW. In: IA-URN-STR 0.2000 kg/d (urine slip). Out: IA-STR-BED 0.2000 kg/d (struvite).

2. Size.
- Envelope 1000×1000×1200 mm, 1.20 m³. That box over this flow would be 144000.0 h if it were full. It is not a residence time.
- Seven-day charge V = (0.2000/1000)×(168/24) = 0.0014 m³.

3. Material. HDPE or PVC for the water. The frame is not the wetted part. Corrosion allowance does not apply to the polymer.

4. Nozzles. At 1.5 m/s and 1000 kg/m³ the bore is 0.04 mm. That is not a specification. Nozzle is DN15. No flange class. Atmospheric tube or hose. Not to the room.

5. Instruments. No trip is specified.

6. Relief. Not a pressure vessel. A vent, if the shell is closed, returns to the process. Not to the room. Stored design_kPa is the old head-plus-10 figure. It is not a set point.

7. Code. Shop. Not stamped.

8. Open items. Envelope volume over flow is not a residence time.
