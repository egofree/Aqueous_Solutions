# Unit duty standard

Document number: AQS-STD-001
Revision: A
Date: 2026-10-10
Authority: study. Not a PE stamp. One page. Applies to every present unit.

A unit is not designed until this page exists for it. The sentence on the graph node is the index. It is not this page.

1. Basis. Flow, composition, temperature, pressure. State the source edge. One operating point, not a range.

2. Size. The calculation and the result. Residence time for a tank. Area and current density for a cell. Stages and reflux for a column. Heat transfer and approach for an exchanger. No size without the arithmetic.

3. Material. Alloy or polymer, corrosion allowance, and the reason. If a coating is the barrier, name the coating and the thickness.

4. Nozzles. Size, rating, and service for each connection. One line each. Include the drain and the vent.

5. Instruments. What is measured and what it trips. Level, temperature, pressure, conductivity, pH. A unit with no trip has no instrument line, and that is stated.

6. Relief. Set point, destination, and why it cannot vent to the room or the atmosphere. If the unit is not pressurized, say so.

7. Code. The standard the vessel is built to, or "shop, not coded" with the reason.

8. Open items. What is assumed. A blank here means the page is unfinished.

Acceptance. All eight lines filled. The size line shows the arithmetic. The graph sentence matches the size line. A unit that fails acceptance is not buildable.
