# Internal working notes

This folder keeps the notes that were used to run the work: handoffs between
sessions, operator run logs, work queues, status boards and plans that the task
plan has since replaced. They are kept, unedited, as history. They are not design
authority, and their statements about status, counts or next steps were true
only on the date they carry.

For current information use:

- the task list: [TASK_PLAN.md](../TASK_PLAN.md) (AQS-PLAN-007), generated from
  the evidence in the repository;
- owner questions and their working defaults: [OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md);
- engineering limits and holds: [PROJECT_PLAN.md](../PROJECT_PLAN.md);
- the plant itself: `flow_graph/plant_flow_graph.json` and the documents
  generated from it (see [the docs map](../README.md)).

Add a page here when it records how work was run rather than what the design
is. Do not cite a page in this folder as the basis for a design value; cite the
graph, a calculation or a registered reference instead.
