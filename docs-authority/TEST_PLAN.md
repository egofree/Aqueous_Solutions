## 1. Rollout

Phases run in the order below; T1 and T2 start at once and in parallel. T3 bench tests start with the drivers that set equipment size (acid loop, BMED, EW). T4 pilots follow the bench results they depend on. T5 calculations close inside their unit tasks. T6 closes at commissioning. A closed item updates its driver or register entry (value, source, needs_verification false) and the commit reruns the solver, `write_graph`, and the checks.

| Phase | Scope | Items | Closes with |
| --- | --- | --- | --- |
| T1 | Owner and site data | 32 | Owner decision or site investigation report |
| T2 | In-house design tests and standard data | 14 | In-house test record or standard data filed against the item |
| T3 | Bench and laboratory tests | 37 | Bench test report with method, data and result |
| T4 | Pilot runs | 21 | Pilot campaign on plant brine / feed |
| T5 | Design calculations and drawings | 121 | Calculation or drawing issued under the named task |
| T6 | Commissioning measurements | 17 | Commissioning record |

Total 242 items: 120 drivers, 122 register entries. Classification rule: first match of the phase regex on the verification test text (see the generator).
